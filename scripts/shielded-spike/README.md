# Shielded spike

Gate G1 must prove a real customer payment and merchant refund before product feature work starts.

The spike will provide five commands:

1. `setup-demo-wallets`
2. `send-payment`
3. `scan-payment`
4. `send-refund`
5. `verify-roundtrip`

The wallet implementation remains unselected until one official supported path passes the complete test. Outputs must be redacted and must classify proof as real, local test, simulated, planned, or not supported.
